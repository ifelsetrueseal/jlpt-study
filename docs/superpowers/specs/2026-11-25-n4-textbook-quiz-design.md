# N4 교재 문제 기능 설계

## 의도

개인용 JLPT N4 학습 앱에서 교재 어휘를 카드로 공부하고, 교재 기출문제와 같은 어휘로 만든 응용문제를 바로 풀 수 있게 한다. 오답을 고르면 정답만 보여주는 데서 끝내지 않고 모든 보기의 읽기·한국어 뜻·오답 이유를 확인할 수 있어야 한다.

## 범위

- 교재에서 검수한 어휘 24개를 기존 단어 덱에 추가한다.
- 교재 원문 한자 읽기 10문제와 N4 응용 5문제를 추가한다.
- 홈에서 문제 풀이 화면으로 이동한다.
- 답을 고른 뒤 정오답, 해설, 보기별 번역과 피드백을 표시한다.
- 로그인, 서버 저장, 랜덤 출제, 전체 68장 자동 출제는 이번 범위에서 제외한다.

## 접근

1. 기존 단어 카드에 문제 상태를 얹는 방식은 카드 복습 흐름과 객관식 흐름이 섞여 제외했다.
2. 별도 퀴즈 페이지와 정적 문제 데이터를 두는 방식을 선택했다. 현재 JSON 번들 기반 구조와 가장 잘 맞고 서버나 새 의존성이 필요 없다.
3. 문제 엔진을 범용화하는 방식은 현재 한 종류의 퀴즈만 필요해 과도하므로 제외했다.

## 구조

- `data/questions.ts`: 문제, 출처, 보기별 해설 데이터
- `lib/quiz.ts`: 선택 결과를 계산하는 작은 순수 함수
- `app/quiz/page.tsx`: 한 문제씩 풀고 해설을 확인하는 모바일 화면
- `app/page.tsx`: 문제 풀이 진입 카드

문제 출처는 `textbook`과 `generated`로 구분한다. 화면에서는 교재 문제와 N4 응용문제를 명확히 표시한다.
